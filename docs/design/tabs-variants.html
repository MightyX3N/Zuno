Tabs: dark mode and other screen sizes

The Tabs pack is the default layout. One pack defines a light and a dark color scheme and a variant per form factor. Everything here uses the same tokens; only the color set and the layout change. The desktop light version is the original design, kept here for comparison.

Desktop

Dark mode is a second token set, not a separate design. The selected channel inverts (light pill on dark), and name colors and the accent are lifted so they stay readable on the dark background.

Tablet

Same structure as desktop with larger touch targets. The member/info panel moves behind a button in the header and slides in from the right, giving chat the space.

Phone

Server tabs become a strip at the top that scrolls sideways; the chevron at its end pulls down the full server list. Channels slide in from the left (menu button or swipe), members from the right. Chat is full screen.

TV

10-foot layout for Android TV: large text, everything reachable with the D-pad, focus shown as an accent ring. Made for reading chat, sitting in voice and, later, watching streams. Typing opens the system keyboard or voice input.

Signing in on a TV

The TV shows the QR and the phone scans it. They connect over the local network, the TV shows a code that is typed on the phone, then the phone sends the account. The server list comes with it, so the TV joins every server at once.
