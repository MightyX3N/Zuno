# layouts

Layout packs decide how the client looks: regions, which built-in components go where, theme tokens, assets, and a mobile variant.
Servers can ship their own pack; users can turn server layouts off.

Built-in packs:

- `tabs`: default. Light theme, servers as tabs along the top
- `terminal`: monospace, IRC-style
- `messenger`: early-2000s instant messenger look
- `deck`: dark, several channels side by side as columns
