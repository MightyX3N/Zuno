Link a device

This link connects another device to a Zuno account. Nothing has been sent: the link only says where to meet.

  1. Open Zuno on the device you want to link.
  2. Choose Link this device (on the welcome screen).
  3. Type these, or paste this page's whole address into the first box:
Server address
Link code

The code works once and expires two minutes after it was shown. Your new device will then show a 6-digit code to type on the other one.
