What you get

Everything runs on servers people host themselves.

Text and voice

Text channels with history, file sharing and replies, plus voice channels for hanging out.

Layouts per server

Each server can ship its own layout and theme. Don't like it? Switch back to your own.

Host from home

Run a server on your own PC and share it through playit.gg. No port forwarding needed.

Encrypted

All traffic between you and a server is encrypted. Your identity is a key on your device, not an account on someone else's site.

Host a server

The server is a small standalone program. Run it on your PC, a VPS, a dedicated server or a NAS.

  1. Run the server

    Start the Zuno server, or press "Host a server" in the desktop client. It sets up its database and your owner key on first run.

  2. Open it to the internet

    At home, create a TCP tunnel in playit.gg pointing at the server's port (plus a UDP tunnel for voice). On a VPS, just open the port.

  3. Share the address

    Send friends the address, for example my-server.at.ply.gg:41234. They add it in Zuno and they're in.
