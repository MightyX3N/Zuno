What you get

Everything runs on servers people host themselves.

Text and voice

Text channels with history, replies and file sharing, plus voice channels for hanging out.

Layouts and addons per server

Each server can ship its own layout, theme and addons like polls, games and leaderboards. Don't like it? Switch back to your own.

Every screen

Windows, Linux, Android phones and tablets, Android TV and the browser. Light and dark mode everywhere.

One account, every device

No passwords. Your identity is a key on your device. Add your phone, PC or TV by scanning a QR code, and all your servers come along.

Encrypted

All traffic between you and a server is encrypted. Direct messages and file transfers are end-to-end encrypted, so not even the server can read them.

Web and iPhone

Use Zuno in any browser, including Safari on iPhone and iPad. Nothing to install. Open the web client.

Host a server

The server is a small standalone program. Run it on your PC, a VPS, a dedicated server or a NAS.

  1. Run the server

    Start the Zuno server, or press "Host a server" in the desktop client. It sets up its database, its server key and your owner key on first run.

  2. Open it to the internet

    At home, create a TCP tunnel in playit.gg pointing at the server's port (plus a UDP tunnel for voice). The free plan is enough. On a VPS, just open the port.

  3. Share the address

    Send friends the address, for example my-server.at.ply.gg:41234. They add it in Zuno and they're in.

Browsers connect on the same port. For voice in the browser the server needs HTTPS: a playit Premium HTTPS tunnel or your own domain. Without it, browser users can still text through the server's built-in web client.
